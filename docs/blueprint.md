# **App Name**: Finsight

## Core Features:

- Transaction Recording: Record income and expense transactions with customizable fields.
- Account & Category Management: Manage and customize accounts and categories to organize financial data.
- Financial Reporting: Generate summary financial reports including Profit & Loss statements, Cash Flow analysis and Customer summary reports.
- Inventory Management: Inventory management: real time management of sales data, automatic update of sales and expense categories with revenue.
- Data Visualization: Real-time interactive visualization using charts and graphs for key financial metrics.
- Transaction Search and Filtering: Search and filter past transactions to review specific periods.

## Style Guidelines:

- Primary color: Dark green (#329932) to evoke a sense of reliability and growth.
- Background color: Very dark gray (#222222) to provide a modern, corporate feel.
- Accent color: Bright green (#90EE90) used to highlight key elements and calls to action, drawing attention to important functions and data.
- Body font: 'Inter', a sans-serif font for its modern, clean, and readable design.
- Headline font: 'Space Grotesk', a sans-serif font to create contrast.
- Use professional, minimalist icons that represent financial concepts.
- Clean and structured layout with clear sections for easy navigation.
- Subtle transitions and animations to provide feedback and guide the user.
